SymbolicSurveys is a full-featured survey management platform built with Laravel 10. It provides an admin dashboard for creating surveys, managing questions, and analyzing responses with export capabilities.

## Features

- **Survey management** - Create, edit, and activate/deactivate surveys
- **Multiple question types** - Support for scale (1-5), multiple choice, and free text questions
- **Public survey links** - Share surveys via unique UUID-based URLs
- **Results analytics** - View response data with aggregated statistics
- **Export options** - Download results as CSV or PDF

## Architecture

SymbolicSurveys follows the standard Laravel MVC architecture:

```
app/
├── Http/Controllers/
│   ├── Admin/           # Admin dashboard controllers
│   │   ├── DashboardController.php
│   │   ├── SurveyController.php
│   │   ├── QuestionController.php
│   │   └── ResultController.php
│   ├── Auth/            # Authentication controllers
│   └── PublicSurveyController.php
├── Models/
│   ├── Survey.php
│   ├── Question.php
│   ├── Answer.php
│   └── User.php
```

## Routes overview

| Route | Description |
|-------|-------------|
| `/admin` | Admin dashboard |
| `/admin/surveys` | Survey management |
| `/admin/surveys/{id}/questions` | Question management |
| `/admin/surveys/{id}/results` | View results |
| `/survey/{uuid}` | Public survey form |
| `/s/{uuid}` | Short public survey URL |
