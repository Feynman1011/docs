## Creating a survey

1. Navigate to `/admin/surveys`
2. Click **Create Survey**
3. Fill in the survey details:
   - **Title** (required) - The name of your survey
   - **Description** (optional) - Additional context for respondents
   - **Active** - Toggle to enable/disable public access

```php
// Survey validation rules
$data = $request->validate([
    'title' => ['required', 'string', 'max:255'],
    'description' => ['nullable', 'string'],
    'is_active' => ['nullable', 'boolean'],
]);
```

## Survey properties

| Property | Type | Description |
|----------|------|-------------|
| `id` | integer | Auto-incrementing primary key |
| `uuid` | string | Unique identifier for public URLs |
| `title` | string | Survey title (max 255 characters) |
| `description` | text | Optional description |
| `is_active` | boolean | Whether the survey accepts responses |
| `created_at` | timestamp | Creation timestamp |
| `updated_at` | timestamp | Last update timestamp |

## Public survey URLs

Each survey gets a unique UUID for public access. Respondents can access surveys at:

- `/survey/{uuid}` - Full URL
- `/s/{uuid}` - Short URL

Only active surveys (`is_active = true`) are accessible to the public. Inactive surveys return a 404 error.

## Managing surveys

### Edit a survey

Navigate to `/admin/surveys/{id}/edit` to modify survey details. Changes take effect immediately.

### Delete a survey

Deleting a survey removes all associated questions and answers. This action cannot be undone.

### View questions

Click **Questions** on any survey to manage its questions at `/admin/surveys/{id}/questions`.

### View results

Click **Results** to see response analytics at `/admin/surveys/{id}/results`.

## Survey model relationships

```php
class Survey extends Model
{
    // Survey has many questions
    public function questions(): HasMany
    {
        return $this->hasMany(Question::class)->orderBy('position');
    }

    // Survey has many answers
    public function answers(): HasMany
    {
        return $this->hasMany(Answer::class);
    }
}
```
